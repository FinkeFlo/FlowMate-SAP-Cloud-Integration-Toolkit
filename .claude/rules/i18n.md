# i18n rules

- Every user-visible string goes through `t('key')` (or `tSub('key', value)` for one placeholder) from
  `features/shared/i18n.ts`. This includes `title`, `aria-label`, `placeholder`, `data-tip`, toast messages,
  confirm texts and error messages shown to the user.
- Keys are camelCase, prefixed by feature (`logThrottleTopLoggers`, `packageDeploySelected`, `resizeToolbar` for
  shared UI). Add the key to **both** `public/_locales/en/messages.json` and `public/_locales/de/messages.json`
  in the same commit; the files must have identical key sets.
- Placeholders use the Chrome `placeholders` format (`$TYPE$` + `"content": "$1"`); never build sentences by string
  concatenation of translated fragments.
- Technical identifiers (iFlow ids, artifact names, HTTP status codes, hostnames) are not translated.
- Log messages for `devLog`/`console.warn` stay English and untranslated.
- Before finishing: `grep -nE '(title|aria-label|placeholder|data-tip)="[A-Za-z]' features/` must return nothing new.
