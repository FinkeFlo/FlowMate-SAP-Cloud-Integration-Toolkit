# Flowmate Extension — Security & UX Audit

**Datum:** 2026-06-30
**Umfang:** Vollständige Extension (WXT + Preact + TypeScript, SAP CPI)
**Methodik:** Vier parallele Audit-Agenten — Extension-Security (Manifest/Permissions/Messaging),
Daten-/Request-Security (CSRF/SSRF/Logging), XSS/DOM-Injection, UI/UX & Accessibility.
Befunde adversarial verifiziert. Verifikationsschritt im Repo: `npm run compile` (kein Test-Framework).

---

## Gesamtbild

Architektonisch solide:

- **Keine Credential-Speicherung** — nur Tenant-Namen/-URLs in `storage.local`; Auth über bestehende SAP-Session-Cookies.
- **Keine gefährlichen DOM-Sinks** — kein `dangerouslySetInnerHTML`, `innerHTML`, `eval`, `new Function`; Preact escaped Text-Nodes automatisch.
- **Dev-Logger korrekt tree-shaken** — alle WebSocket-Pfade hinter `import.meta.env.DEV`.

Die realen Risiken liegen in **fehlender URL-Validierung an Vertrauensgrenzen** (Security)
und in **fehlender Design-/i18n-/A11y-Infrastruktur** (UI/UX).

## 🔒 Security

### HIGH

#### S1 — Background-Handler validiert weder Sender noch `baseUrl`/`urls` → SSRF & Cross-Tenant-Datenabzug
**Dateien:** `entrypoints/background.ts:21,63,66,118` · `features/shared/fetch-client.ts`

Der `browser.runtime.onMessage`-Listener ignoriert den `_sender`-Parameter vollständig (keine
Prüfung von `sender.id`/`origin`/`tab.url`). `baseUrl` wird ungeprüft aus dem Content-Script
(`window.location.origin`) übernommen und im Background direkt in eine `fetch`-URL konkateniert —
**mit `credentials: 'include'`**. `MSG_OPEN_TENANT_TABS` ruft `tabs.create({url})` für eine
beliebige, vom Absender gelieferte URL-Liste auf.

**Szenario:** Ein bösartiges/kompromittiertes Frame (erreichbar via S3) kann Metering-/Trace-Daten
fremder `*.hana.ondemand.com`-Tenants mit Ambient-Credentials abziehen oder beliebige Tabs öffnen.

**Eingrenzung:** Kein `externally_connectable` deklariert → Webseiten können nicht direkt
`runtime.sendMessage` senden. Daher **High**, nicht Critical.

**Empfehlung:**
- Listener: `if (sender.id !== browser.runtime.id) return;` + `sender.tab?.url` gegen striktes Pattern prüfen.
- `baseUrl` im Background gegen Allowlist validieren (`https:`, Host endet auf `.hana.ondemand.com`) — besser: aus `sender.tab.url` ableiten statt vom Content-Script übernehmen.
- `MSG_OPEN_TENANT_TABS`-URLs identisch validieren vor `tabs.create`.

#### S2 — `tenant.url` wird nur im Add-Formular validiert, nirgends beim Verwenden
**Dateien:** `features/settings/settings.ts:103-121` · `entrypoints/background.ts:118-145` · `features/message-usage/ExportButton.tsx:133,147`

`validateCpiUrl()` (strikte Regex, HTTPS-only) greift nur in `AddTenantForm`. Storage-Layer
(`addTenant`/`updateTenant`/`saveSettings`) und `handleOpenTenantTabs` validieren **nichts**.
`tabs.create` öffnet ungeprüft jede URL (auch `javascript:`/`http:`). Ein Import-Feature oder
direkte Storage-Manipulation umgeht den einzigen Check.

**Empfehlung:** `validateCpiUrl` im Storage-Layer **und** erneut in `handleOpenTenantTabs` vor
`tabs.create` erzwingen. Defense-in-depth: zusätzlich beim Lesen in `getSettings()`.

#### S3 — Mount-Guard `.includes('integrationsuite')` per Substring umgehbar
**Datei:** `entrypoints/content.ts:15`

```ts
if (window !== window.top || !window.location.hostname.includes('integrationsuite')) return;
```

`integrationsuite-x.hana.ondemand.com` oder `foo.integrationsuite.hana.ondemand.com` passieren
den Guard. Wer eine beliebige `*.hana.ondemand.com`-Subdomain mit diesem Substring kontrolliert,
erzwingt das Mounten im Top-Frame → öffnet den Pfad zu S1.
*(Die `integrationsuite.evil.com`-Variante schlägt fehl, da `matches` nur `*.hana.ondemand.com` injiziert.)*

**Empfehlung:** Exakten Hostnamen-Match per Regex gegen das reale Tenant-Hostschema statt freiem Substring; mindestens auf `.integrationsuite.` als Label-Grenze prüfen.

### MEDIUM

#### S4 — `host_permissions`/`matches` zu breit
**Dateien:** `wxt.config.ts:134` · `config/sap-cpi-urls.ts:7`

`*://*.hana.ondemand.com/*` umfasst die gesamte SAP-Shared-Domain und erlaubt auch `http:`.
**Empfehlung:** Auf `https://*.integrationsuite.*.hana.ondemand.com/*` einengen, `http` entfernen.

#### S5 — Business-/PII-Daten in `.dev-logs/`
**Dateien:** `features/log-throttle/usage-api.ts:100` · `features/trace-mode/trace-api.ts:23,46`

`devLog.response()` schreibt vollständige API-Response-Bodies (Tenant-Metriken, Artefakt-Metadaten)
auf Platte, bis zu 3 Tage. Nur Dev-Modus, korrekt geguarded. *(Positiv: Trace-Message-Payload wird
nur per `length` geloggt, nicht im Klartext.)*
**Empfehlung:** `.dev-logs/` in `.gitignore` bestätigen; Identifier in `devLog.response` redacten; dokumentieren, dass Dev-Modus nicht gegen Produktiv-Tenants laufen soll.

#### S6 — `extractHost`/`buildTenantUrl` geben rohen Input bei Parse-Fehler zurück (fail-open)
**Datei:** `features/tenant-links/tenant-url-builder.ts:27-46`

Bei URL-Parse-Fehler `return fullUrl;` statt zu verwerfen → ungültige Eingabe wird durchgereicht
und in navigierbare URL konkateniert. Verstärkt S2.
**Empfehlung:** Bei Parse-Fehler leer zurückgeben/werfen; Caller überspringt den Link (fail-safe).

#### S7 — Undeploy-Ziel per DOM-Textabgleich spoofbar
**Datei:** `features/package-design/ArtifactUndeployButton.tsx:21-60`

Undeploy-Ziel wird über DOM-Textknoten gegen `deployedMap` gematcht. Artefakt-Namen sind
User-Content; ein kollidierender Name könnte das falsche Artefakt selektieren. `window.confirm` mildert.
**Empfehlung:** Stabilen `artifactId` (data-Attribut) statt Freitext matchen; Confirm beibehalten.

### LOW

| # | Befund | Datei |
|---|--------|-------|
| S8 | `window.open(msg.AlternateWebLink)` ohne Protokoll-Check — `new URL()`-Schema-Prüfung ergänzen | `message-log/MessageLogPanel.tsx:116` |
| S9 | CSV-Formel-Injection — führende `= + - @` neutralisieren (Excel) | `message-usage/csv-exporter.ts:68` |
| S10 | Keine Style-Isolation / kein Shadow DOM — aktuell sauber gescopt, aber fragil; `createShadowRootUi()` erwägen | `entrypoints/content.ts:20` |
| S11 | CSP nicht explizit gepinnt (Default ist sicher); `externally_connectable` weiterhin **nicht** setzen | `wxt.config.ts` |

### Verifizierte Non-Findings
- **Kein XXE** — Browser-`DOMParser` löst keine externen Entities auf.
- **Keine Prototype-Pollution** — native `response.json()`, feste Property-Pfade, kein Recursive-Merge untrusted JSON.
- **Timeouts korrekt** — `AbortController` + `clearTimeout` im `finally` (30s Background / 15s fetch-client).
- **Keine Credential-Speicherung** — nur `cpi-settings` in `storage.local`.

## 🎨 UI/UX & Accessibility

### HIGH

#### U1 — Tote Tailwind/daisyUI-Klassen in der Toolbar (echter Bug)
**Datei:** `features/design-tools/DesignTimeToolbar.tsx:44-62`

Tailwind v4 + daisyUI sind als Dependencies installiert, aber **nie aktiviert** (keine `tailwind.config`,
kein `@import "tailwindcss"`). Die Utility-Klassen (`flex`, `text-base-content`, `bg-base-content/5`,
`rounded-md`) werden nirgends generiert und haben **keine Wirkung**.
**Empfehlung:** Tailwind/daisyUI korrekt aufsetzen **oder** Utility-Klassen durch echte CSS-Klassen ersetzen.

#### U2 — Content-Features komplett hartkodiert (Englisch)
`t()` wird nur in `message-usage/` und `settings/` genutzt. **Null** i18n in `design-tools`,
`message-log`, `inline-trace`, `log-throttle`, `trace-mode`, `package-design`, `shared/toast`.
Ein deutscher Nutzer sieht die gesamte In-Page-UI auf Englisch, obwohl Infra + DE-Locale (124 Keys) existieren.
**Empfehlung:** Alle sichtbaren Strings (inkl. `title`/`aria-label`) auf `t()` umstellen, Keys in beide Locales ergänzen.

#### U3 — Modals ohne Dialog-Semantik & Focus-Trap
**Dateien:** `features/message-log/MessageDetailPopup.tsx` · `features/inline-trace/TraceStepPopup.tsx`

Overlays sind nackte `<div>` ohne `role="dialog"`/`aria-modal`/`aria-labelledby`, kein Focus-Trap,
kein Initial-Fokus. Icon-`X`-Buttons ohne `aria-label`. Tab-Fokus wandert hinter das Overlay in die SAP-Seite.
**Empfehlung:** `role="dialog"` + `aria-modal` + `aria-labelledby`; Initial-Fokus auf Close; Tab-Zyklus einfangen; Fokus beim Schließen zurückgeben; `aria-label` an alle `X`.

#### U4 — `window.confirm` als blockierende Bestätigung
**Dateien:** `features/log-throttle/LogThrottlePanel.tsx:94,143` · `features/package-design/ArtifactUndeployButton.tsx:68`

Natives `window.confirm` ist blockierend, bricht das Glass-Theme, ist nicht i18n-fähig. Eine
`ConfirmDialog`-Komponente existiert bereits in `features/settings/components/ConfirmDialog.tsx`
und wird in den Content-Features ignoriert.
**Empfehlung:** `ConfirmDialog` (oder shared-Variante) wiederverwenden.

#### U5 — Z-Index-Stapel inkonsistent
| Element | z-index |
|---|---|
| `design-toolbar` | 9999 |
| `mpl-panel` (Dropdown der Toolbar) | 10000 |
| `ExportButton` | 999999 |
| Modals/Trace/DateRange | 9999999 |
| Toast | 10000000 |

Die Toolbar (9999) liegt unter ihrem eigenen Dropdown und unter dem Export-Button; SAP-UI5-Dialoge
(~1–10 Mio) können sie verdecken.
**Empfehlung:** Zentrale z-index-Skala als Tokens (`--fm-z-toolbar/panel/modal/toast`) mit klarer Ordnung; Toolbar über typische SAP-Layer heben.

#### U6 — Keine Design-Tokens → driftende Werte
Kein `:root`-Block; jede CSS dupliziert Literale. Folgen:
- **3 konkurrierende Brand-Blautöne:** `#0070F2` (Logo), `#0a6ed1` (Fiori, 19×), `#6366f1`/`#4f46e5` (Indigo, Tabs).
- **4 Grüns** für „OK/Erfolg": `#13af00`, `#10b981`, `#107e3e`, `#86efac`.
- **10+ Border-Radii**, Mischung `rem`/`px`.
- **Uneinheitliches Glassmorphism** (`blur(8/12/16px)`, wechselnde Container-RGBA).
- **Der Toast ist hell** (`#f1fdf4`/`#fef2f2`, Text `#333`) und bricht aus dem Dark-Theme.

**Empfehlung:** `tokens.css` mit `--fm-accent`, `--fm-radius-*`, `--fm-glass-bg`, `--fm-border`,
`--fm-text-*` anlegen; eine Brand-Farbe (`#0070F2`) festlegen; Toast ans Theme angleichen oder bewusst dokumentieren.

## 🎯 Empfohlene Reihenfolge

**Sofort (Security-kritisch, klar abgegrenzt):**
- **S1 + S2 + S3** zusammen: Sender-Check (`sender.id === runtime.id`) + `baseUrl`/`urls`-Allowlisting (`https:` + Host-Regex) im Background + Label-genauer Mount-Guard. Schließt den real ausnutzbaren Pfad.

**Quick-Wins (kleiner Aufwand, hoher Nutzen):**
- **U1** tote Tailwind-Klassen · **U4** `window.confirm` → `ConfirmDialog` · **S8/S9** URL-/CSV-Härtung · **S5** `.gitignore`-Check.

**Mittlere Brocken:**
- **U6/U7/U8** Design-Tokens + Kontrast + Fokus · **U3** Modal-A11y · **U2** i18n-Nachzug · **U5** z-index-Skala.
